# Student Management System

A simple **Python console-based project** to manage student records.  
This project allows you to **add, view, search, and delete student information** easily.

---

## Features

- ✅ Add a new student with roll number, name, and marks  
- ✅ View all students  
- ✅ Search for a student by roll number  
- ✅ Delete a student by roll number  
- ✅ Exit the program safely  

---

## Technologies Used

- Python 3  
- Basic knowledge of dictionaries, loops, and functions
